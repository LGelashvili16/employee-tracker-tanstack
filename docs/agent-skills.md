# Project-local agent skills

The project vendors selected skills in `.agents/skills/`. They supplement the architecture and security rules in `AGENTS.md` and the installed TanStack package skills accessed through `pnpm exec intent list` and `pnpm exec intent load`.

Only task-relevant skills should be loaded. This installation supplies guidance and reference assets; it does not install Vitest, React Testing Library, React Email, GSAP, browser services, or other application/runtime tools.

## Provenance and updates

- `agent-skills.lock.json` records each installed skill's upstream repository, source directory, immutable commit, source URL, and content hashes. These are vendored snapshots, not automatically updated packages.
- Installations used the Codex skill installer's explicit project-local destination. No upstream skill script, launcher, hook, or embedded shell command was executed during installation.
- Review upstream changes before replacing a snapshot. Preserve any supplied licenses and validate referenced files. Do not use a broad update-all command or edit upstream examples silently to claim they are compatible.
- Codex can discover project-local skills on a subsequent turn. If the active session does not list them yet, consult the explicit local paths above. Intent continues to manage package-provided skills separately.
